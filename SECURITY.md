# Security policy

## Report a vulnerability

Please report security vulnerabilities privately through the Security contact
option at [crawlora.net/contact](https://crawlora.net/contact). Do not report a
vulnerability in a public issue or pull request.

Include the affected repository or service, the version or commit if known, the
potential impact, and steps to reproduce. Do not include real API keys,
passwords, cookies, or other credentials in your report.
